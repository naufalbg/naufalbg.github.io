Autonomous Disaster Response Robot Using TurtleBot3

In this project, I built an autonomous disaster response system on top of the TurtleBot3 platform. The main goal was to have a robot capable of navigating hazardous environments and actively detecting emergency signals during search-and-rescue operations.

To make this happen, I integrated the ROS2 Navigation Stack with Gazebo simulations, relying on RGB vision and LiDAR sensing. What I'm really proud of is implementing Behavior Trees using the py_trees library, which allowed the robot to dynamically switch tasks, avoid obstacles, and make autonomous decisions on the fly.

The emergency markers were detected using HSV color thresholding. When I tested it in simulated disaster environments, the robot operated reliably, and I'm excited about how this sets the stage for future multi-robot coordination and reinforcement learning approaches.
